# 定時起動係（Cloudflare Worker）の設定手順

GitHub の定時実行が10時間以上遅れるため、Cloudflare から決まった時刻に起動します。
無料プランで足ります（Cron は3本使用／上限5本）。所要 10〜15分。

トークンの値は、ぼじぃさん本人が GitHub からコピーして Cloudflare に貼るだけです。Claude には渡さないでください。

---

## 1. GitHub で起動用トークンを作る（約3分）

1. https://github.com/settings/personal-access-tokens/new を開く
2. 入力する項目
   - Token name：`brc-dispatcher`
   - Expiration：`366 days`（最長。期限の前に作り直す）
   - Repository access：**Only select repositories** → `bozzy-star/baseballreportcard` だけを選ぶ
   - Permissions → Repository permissions → **Actions：Read and write**（これ以外は触らない。Metadata: Read は自動で付く）
3. 一番下の **Generate token** → 表示された `github_pat_...` をコピー
   - この画面を閉じると二度と表示されないので、次の手順まで閉じない

## 2. Cloudflare で Worker を作る（約3分）

1. https://dash.cloudflare.com → 左メニュー **Compute（Workers）→ Workers & Pages**
2. **Create** → **Start with Hello World!**（または Create Worker）
3. 名前を `brc-dispatcher` にして **Deploy**
4. **Edit code** → 中身を全部消して、`ops/dispatcher/worker.js` の内容を貼る → **Deploy**

## 3. トークンを Secret として登録（約1分）

1. Worker の画面 → **Settings → Variables and Secrets → Add**
2. Type：**Secret**、Variable name：`GITHUB_TOKEN`、Value：手順1でコピーした値
3. **Deploy**（または Save）

## 4. 定時起動を3本登録（約2分）

Worker の画面 → **Settings → Trigger Events（Triggers）→ Add → Cron Triggers** で、次の3つを1本ずつ追加：

| Cron（UTC） | 日本時間 |
|---|---|
| `33 5 * * *` | 14:33 高校の部 |
| `7 7,8,11,13 * * *` | 16:07 / 17:07 / 20:07 / 22:07 |
| `37 9 * * *` | 18:37 大学の部の再確認 |

## 5. 確認

- Worker の URL（`https://brc-dispatcher.<アカウント名>.workers.dev`）を開いて
  `brc-dispatcher ok / token set` と出れば設定完了
  - `token missing` なら手順3をやり直す
- 最初の定時（14:33 か 16:07 など）のあと、GitHub の Actions 画面に
  「workflow_dispatch」で起動した実行が数分以内に出ていれば成功
- 失敗したときは Worker の **Logs**（Observability）に `dispatch ... -> 401` などが出る
  - 401/403：トークンの権限かリポジトリ選択が違う
  - 404：リポジトリ名かファイル名の違い

ここまで終わったら「設定した」と一言ください。Claude 側で最初の起動を確認します。

---

### メモ
- GitHub 側の定時実行は予備として残しています。遅れて2回目が動いても、処理済みの試合は飛ばすので重複投稿はされません
- トークンの期限が切れると止まります。1年後に手順1と3だけやり直してください
